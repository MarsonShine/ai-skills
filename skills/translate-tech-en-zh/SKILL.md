# 英文技术内容 → 中文翻译

将独立的英文技术文本、文件或网页译为自然、准确的中文。

## 读取与翻译

1. 已提供正文时直接翻译；文件读取内容；URL 使用可用网页读取或浏览器工具提取正文。仅在需要文件处理或用户要求保存时下载，使用用户指定位置或允许的工作/临时目录。
2. 网页抓取失败时尝试可用的替代读取方式。仍无法取得正文，说明缺失内容并请用户提供；不把登录页、错误页或搜索摘要当作全文。
3. 保留段落顺序、标题层级、列表、引用、链接及术语含义。常用术语用业内译法；不确定的专名保留英文。原文给出缩写全称时同时保留。
4. 保留代码的逻辑、标识符、字符串、命令和缩进，保留 fenced code block 的语言标签。可翻译解释性注释；指令型注释、测试断言、文档测试和具有机器语义的注释保持原样。用户要求代码逐字保留时不翻译任何代码内注释。

## 交付

默认只给译文，不附开场白、总结或点评。用户明确要求术语说明、对照或其他格式时按其要求输出；内容不可取得或无法完整交付时如实说明限制。

普通英译中不触发仓库双语同步。仅当用户要求维护仓库中的双语配对时使用 `../sync-bilingual-docs/SKILL.md`，不因材料来自仓库或同时包含中英文而切换。
