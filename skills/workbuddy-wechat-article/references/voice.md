# AI 味检测

`scripts/voice.py` 是纯正则与统计的确定性检测器：同一份 blocks 和 profile，输出逐字节一致。它不调用模型，也不修改原文。

## 输入

- `blocks`：`lead`、`p`、`h2`、`h3`、`footer` 的 `text`；`quote` 的 `text`/`source`；`list`/`callout` 的 `items[]`；场景块里的 `text`、`note`、`dialogue.lines[].text`、`timeline.items[].title`。
- `code`、`image.caption` 不参与行文检测。
- 引号、书名号、`quote` 块内的命中只记录为 `keep`，不扣分。

## 负向规则

| 类别 | 规则 | 严重度 |
| --- | --- | --- |
| 套话词 | 硬禁 13 词：赋能、闭环、抓手、底层逻辑、颗粒度、组合拳、护城河、顶层设计、降本增效、颠覆式、沉浸式、全链路、生态位；每个命中 2 | 2 |
| | 慎用 14 词：首先、其次、最后、综上、总而言之、不难发现、值得注意的是、众所周知、显而易见、某种程度上、一定程度上、某种意义上、不得不说、在这个时代；每个命中 1；命中数/(字数/1000) > 2 再加一条“密集慎用” | 1 |
| 句长 | 正文句数 ≥8 且 CV < 0.32 | 2 |
| | 连续 4 句 max−min ≤ 3 | 1 |
| 修辞 | 破折号密度 > 0.33/百字，或全文 ≥3，或单句 ≥2 | 2 |
| | 否定式排比：不是…而是、不只是…更是、并非…而是、not just…but；每次 2 | 2 |
| | 三连排比：单句内三个 2–10 字、长度差 ≤2、首尾有共享字的短句，或“既…又…还”“不仅…还…更”“一…二…三” | 2 |
| 段落 | ≥4 段时 (max−min)/mean < 0.22 | 1 |
| | ≥5 段且 80% 落在同一 20 字窄带 | 2 |
| 结尾 | 结尾套话且该段具体细节密度为 0：未来可期、值得期待、充满希望、越来越好、明天会更好、无限可能、共勉、愿你我、一切都会好、新的开始、继续前行、加油；“希望/愿…都能/可以/会”“这就是…的意义” | 2 |

破折号、否定式排比、三连排比各自单次出现时只进 `keep`，理由是“可能是作者固定语感”。纪念日场景里带“祝/祝福”的结尾降级为 `keep`。

## 正向规则

| 指标 | 基线（日常/家庭/旅行） | 计分 |
| --- | --- | --- |
| 具体细节密度（数字量词、时间、专名、动作动词、感官词加权/百字） | 1.2（纪念日 1.0） | 35 |
| 第一人称句占比 | 0.18（纪念日 0.12） | 20 |
| 短句（≤12 字）占比 | 0.22 | 20 |
| 句长 CV | 0.35 | 15 |
| 感官词/百字 | 0.5 | 10 |

正向项 `level` 为 `ok`/`warn`，不直接扣分，但参与 `human` 分；`human < 40` 时最终档位强制降一档。写得干净但没有活人气息，同样拿不到高分。

## 聚集才判罚

信号先按“同一 block 或相邻两个 block”聚簇。一个簇满足以下任一条件才扣分：

- 信号数 ≥3 且类别 ≥2；
- 硬禁词同簇 ≥2；
- 否定式排比或三连排比同簇 ≥2；
- 破折号全文 ≥3。

都不满足但全文类别 ≥3、信号 ≥5，则整篇弱信号按严重度 1 计入。未成簇的信号全部进入 `keep[]`，附理由。

## 分数

- 各类别扣分上限：套话 25、句长节奏 20、修辞 20、段落 15、结尾 10。严重度 1/2/3 分别扣 3/6/9。
- `ai = clamp(100 − 扣分, 10, 100)`。
- `human = 35×细节 + 20×第一人称 + 20×短句 + 15×CV + 10×感官`（各按上限截断）。
- `final = round(0.6×ai + 0.4×human)`。
- 分档：85–100 人味足；70–84 可用，少量机器味；55–69 明显 AI 味；0–54 机器味重。
- `human < 40` 且不是最低档时降一档，`gate` 记为 `human_low_downgraded`。

## 输出

```json
{
  "meta": {"chars": 1180, "sentences": 42, "paragraphs": 9, "scene": "daily", "profile": "阿柯"},
  "scores": {"final": 68, "ai": 62, "human": 78, "band": "明显AI味", "gate": "human_ok",
             "deductions": {"lexicon": 12, "rhythm": 0, "rhetoric": 6, "paragraph": 0, "ending": 0}},
  "issues": [{"id": "i1", "code": "neg_parallel", "category": "rhetoric", "severity": 2,
              "penalized": true, "sentence_id": "5:text:1", "span": [12, 38],
              "sentence_text": "……", "evidence": "不是…而是…", "cluster_id": "c2"}],
  "clusters": [{"id": "c2", "categories": ["rhetoric"], "signals": 2, "penalized": true, "deduction": 12}],
  "keep": [{"code": "short_sentence", "sentence_id": "8:text:2", "text": "今天很累。", "reason": "短句是人的呼吸"}],
  "positive": [{"code": "detail_density", "value": 0.9, "baseline": 1.2, "level": "warn"}],
  "targets": [{"sentence_id": "5:text:1", "text": "……", "before": "……", "after": "……", "issues": []}]
}
```

`targets` 只包含可被单句改写的命中（套话词、破折号、排比、空洞结尾）；段落均匀、句长整体均匀这类全局问题只出现在 `issues`，不硬塞给某一句。

## 不要这样做

- 不要为了让 `final` 变高删掉短句、口头禅、具体细节或未解决的情绪。
- 不要把 `keep` 里的句子改掉；它们是作者语感。
- 不要用另一套模板化口语替换 AI 腔，那仍然是 AI 味。
