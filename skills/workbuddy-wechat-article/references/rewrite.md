# 定点改写

只改诊断器点名的句子，一次一句。不要重写整段，不要顺手调整排版。

## 取目标

`check` 的 `targets[]` 已经给出：

```json
{
  "sentence_id": "3:text:1",
  "block_index": 3,
  "field": "text",
  "sentence_index": 1,
  "text": "这不是一次普通的搬家——而是我们第一次真正离开父母。",
  "before": "……",
  "after": "……",
  "issues": [{"code": "neg_parallel", "severity": 2, "evidence": "不是…而是…", "message": "否定式排比"}]
}
```

`sentence_id` 的格式是 `block_index:field:sentence_index`，在两轮改写之间保持稳定。

## 给模型的指令

一次调用只处理一句。把账号声音、问题、目标句和前后句一起给它，不要附全文。

```text
你是中文编辑。只改写【目标句】这一处，其余一律不动。

账号声音：{tone} / 人称={person} / 句长习惯={sentence_len} / 口头禅={catchphrases}
本句问题：{code 与一句原因，例如「否定式排比：不是X而是Y」}
目标句：「{sentence}」
上一句（仅帮助理解，禁止修改）：「{before}」
下一句（仅帮助理解，禁止修改）：「{after}」

硬性要求：
1. 只输出 JSON：{"rewrite": "改写后的这一句"}，不要解释，不要输出上下文。
2. 不新增原文没有的事实、数字、时间、人名、地名、引用。
3. 原句里的数字、专名、引号内容必须原样保留。
4. 改写后与原文长度相差不超过 40%，且仍是一句话。
5. 不新增破折号，不使用「不是…而是…」，不堆三连排比。
6. 如果这句本身没问题，输出 {"keep": true, "reason": "具体原因"}。
```

第 6 条是“模型可拒绝”通道。句子本身没问题时明确说没问题，比为改而改更可靠。

## 写成文件

```json
[
  {"sentence_id": "3:text:1", "rewrite": "那天搬家，我第一次觉得，离开父母是件具体的事。", "reason": "拆掉对仗，换回当天的一个动作"},
  {"sentence_id": "5:text:0", "keep": true, "reason": "短句是人的呼吸，不是缺陷"}
]
```

```text
python -X utf8 scripts/article.py rewrite --blocks 文章.json --report voice.json --rewrites rewrites.json --out blocks.2.json --changes changes.json
```

输出 `applied`、`changes[]`、`rejected[]`、`keep[]`。`rejected` 里的句子保留原样。

## 四道校验

每句改写必须全部通过，否则丢弃并冻结：

1. **结构不变**：只替换目标句的 span，同一 block 的前后缀原样保留；其他 block 逐字节不变。
2. **句数不变**：新句按 `。！？!?…` 切分后仍是一句。
3. **事实不丢**：原句的数字、中文数量、时间表达式、`《》`/引号专名必须出现在新句里。缺失即拒绝。
4. **长度护栏**：新句/原句在 0.60–1.45 之间，且 `new != old`。

另外，改写不得新增硬禁词；这不是为了分数，而是不要让“去 AI 味”变成换一套套话。

## 两轮终止

- 第一轮：对全部 `penalized` 的 `targets` 各改一次。
- 同一句只改一次，成功后冻结；第二轮不再碰。
- 第二轮结束或触发任一条件即停：没有新的 `penalized` 句子；分数提升 < 2；`final ≥ 85`；没有成功改写。
- 同一句第二轮仍被判同类问题，直接冻结并写入 `keep`，理由“二次诊断仍命中，可能为个人风格”。

## 给作者看的改动清单

固定四段式：

```text
【去 AI 味 · 第 1 轮】人味 62 → 78，改 3 句，保留 4 处

1) 第 2 段 · 第 1 句 [否定式排比 + 破折号]
   原：这不是一次普通的搬家——而是我们第一次真正离开父母。
   改：那天搬家，我第一次觉得，离开父母是件具体的事。
   理由：拆掉「不是…而是」对仗，把抽象判断换回当天的一个动作。

保留（看着像问题，但建议不动）：
· 第 5 段「今天很累。」—— 短句、单点信号，像人的呼吸。
· 第 3 段「说起来有点矛盾」—— 未解决的情绪，是活人痕迹。

需要你补的真实细节：
· 第 2 段只写了“搬家”，没有具体时间、地点或物件；AI 补不出来，请你补一句。
```
