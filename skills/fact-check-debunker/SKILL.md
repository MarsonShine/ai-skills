# 辟谣与事实核查

核查具体事实主张，给出可追溯的结论。观点和预测只核查其中可验证的事实部分。

## 工作流程

1. 识别核心主张；包含不同事件、数字或因果关系时拆开核查。
2. 查找原始来源与完整上下文，核对时间、地点、人物、数字和引用。重大或有争议的事件寻找独立证据；多个转述同一消息的网页不算交叉验证。
3. 区分来源报告的内容与已被证据证实的事实。涉及旧闻、事件演变或更正时再整理时间线。
4. 根据证据给出真实、基本真实、部分真实、误导、虚假、存疑或暂无足够证据的判断；不把“未证实”写成“虚假”。

需要证据等级、截图/视频处理、高风险主题或复杂结论时，读取 `references/verification-playbook.md`。

## 输出

先给结论，再给直接支持判断的来源链接、关键依据和限制。实时事件和高风险主题注明信息更新时间。多项主张可用表格，简单主张用短段落即可。

说明置信程度的证据依据，不默认生成无校准的 0–100 分。用户要求评分时说明评分方法与局限。仅在有助于纠正传播内容时补充更准确的转述。
