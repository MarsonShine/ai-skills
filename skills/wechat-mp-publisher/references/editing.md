# 作者偏好与改稿

预览依次读取 `--profile 文件`、文章目录的 `profile.yaml`、用户主目录下的 `.config/wechat-mp/profile.yaml`。没有文件即可使用默认版式。对话只收集作者愿意长期保留的偏好，无须家庭成员档案。显式指定的场景和署名优先。

```yaml
person: first
tone: 朴素，像给老朋友写信
author: 阿禾
avoid: [赋能, 沉浸式]
whitespace: airy
scene: daily
```

字段均可省略。人称可选 first、third，留白可选 tight、normal、airy。署名最多 16 字。人称和语气指导经授权的润色；排版模式保留原文。预览会列出含避用词的原句供作者决定。保存时先给用户看字段和目标文件，确认后将相同字段以 UTF-8 JSON 送入 `python -X utf8 scripts/profile.py --save --file 目标路径` 的标准输入；也可以直接手填相同 YAML。

## 润色

由当前 Codex 根据原文与偏好起草逐处改动，重点核对否定、人物关系、日期、数量和引语。可以原样保留。缺少真实细节时，只在聊天里向作者核实。不要把追问或修改理由写进文章。给出修改前、修改后和理由，记录为 JSON 数组，再用原来的 `--text-file` 和新增的 `--edits 修改文件` 生成新版。重复出现的原句用从 1 开始的 `occurrence` 指定。

```json
[{"before":"回去的时候天已经黑了。","after":"回去时，天已经黑了。","reason":"收紧句子，保留天色和时间顺序。"}]
```

每项修改必须能定位到原文且互不重叠。审阅页展示差异。作者拒绝某项时，从修改列表删去该项，用同一原文再生成预览。作者愿意提供过往文章时，先征得同意再将反复接受或撤回的措辞整理成长期偏好。

## 素材与版式

- `--image` 可反复使用，也可传 `--images 文件1 文件2`。可指定独立封面路径 `--cover`。重复的 `--caption` 与原照片一一对应，跳过中间图注时传空字符串。题记用 `--epigraph`，标题、摘要和署名用 `--title`、`--digest`、`--author`。
- 布局文件示例为 `{"scene":"travel","order":[2,1],"cover":2}`。图号均从 1 开始指向最初的输入顺序。沿用初始照片列表及图注再运行 `preview --layout 布局文件`。新版本保存在同一文章目录，原预览可继续查看。
- 默认 `--quality balanced`。选 `lossless` 要求本地副本解码后的像素相同；超限时显示具体文件，可换图或经用户同意改画质。远端图片未经像素比较时报告未核验。
- 固定二维码尾部用 `--footer-image 二维码文件 --footer-text "扫一扫二维码\n快来关注"`。二维码在正文图片后居中显示，文字另起行；页尾图单独无损准备，确保本地像素不变。换行请传入实际换行符。
