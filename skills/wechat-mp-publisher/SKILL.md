# 微信公众号图文草稿助手

当用户给出有序照片和原文，先生成可打开的本地预览。默认逐段保留原文与引语，首图作候选封面，从原文摘标题和摘要。家庭、旅行、日常、纪念日分别对应 `family`、`travel`、`daily`、`anniversary`。场景可根据原文选择，缺少线索用日常。图注、题记、时间和地点只采用用户提供的信息。

## 出预览

运行环境为 Node.js 22.18 或更高版本、Python 3 和 Pillow；使用 YAML 偏好还需要 PyYAML。如遇缺包，用所选 Python 运行 `-m pip install -r requirements.txt`。命令中的脚本路径相对于本技能目录，照片、文本和文章工作目录使用用户工作区的绝对路径。

```text
node scripts/wx_publish.ts preview --images 照片1 照片2 --text-file 原文.txt --scene family --workdir 文章目录
```

把返回的 `previewPath` 作为可点击文件交给用户，说明标题、封面及图片顺序。文章目录属于这一篇文章；换一篇用新目录。改稿继续使用同一目录。用户可以在预览中导出布局选择，也可以直接说“第二张当封面”或“改成旅行版”。用原始素材和 `--layout 布局文件` 或对应参数再生成预览，并展示新版本。

作者未要求润色时，只提示可能值得复核的句子。已有作者偏好直接复用；选择保存偏好、用户要求润色，或需从实际采用的修改打磨文风时，读[作者偏好与改稿](references/editing.md)。首次预览可跳过建档和在线验号。

## 确认并写入

用户首次配置或不熟悉公众号时，引导阅读[首次配置与发文教程](README.md)；密钥只在本机配置，不在聊天中收集。

1. 确定目标公众号的 AppID 和新建或更新操作。用 `check --offline --account AppID --bundle 版本目录 --action draft` 取得绑定账号、操作与版本的确认码；更新用 `update` 作为 action。向用户展示账号、操作、标题及刚生成的预览，等待确认。一次同意涵盖此版正文图、永久封面素材上传及草稿写入。确认码由 Codex 传递。
2. 获取确认后，执行 `draft --bundle 版本目录 --account AppID --confirmed 确认码`，或同参数的 `update`。两者均通过上述 Node 脚本运行。正文、图片或目标账号有变化时，展示新选择后重新确认。
3. 按实返回标题、media_id、逐项回读结果和后台入口。有临时查看链接时也一并给出，提醒作者在微信预览实际裁切和排版，最后手动发表。创建结果未知、回读失败或发现人工改稿时，按[微信接入与恢复](references/wechat.md)处理。
