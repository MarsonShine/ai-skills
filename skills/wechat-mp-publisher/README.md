# 微信公众号图文助手：首次配置与发文教程

本技能可以根据照片和文字生成本地预览，并在你确认后把图文写入公众号草稿箱。最终发表需要你在微信公众平台完成。**只看本地预览不需要配置公众号，也不会上传照片。**

## 一、注册或登录公众号

1. 用电脑打开[微信公众平台](https://mp.weixin.qq.com/)。已有公众号时，登录后继续第二步。
2. 如果没有公众号，点击“立即注册”，按页面提示选择适合自己发布文章的公众号类型，完成注册和身份验证。可参考[微信官方注册指引](https://kf.qq.com/faq/120911VrYVrA151013MfYvYV.html)。
3. 准备好公众号管理员的微信，后续操作可能需要扫码验证。

## 二、获取 AppID 和 AppSecret

AppID 是公众号的应用编号；AppSecret 是调用接口的密钥。两者应属于同一个公众号。

1. 打开[微信开发者平台](https://developers.weixin.qq.com/platform/)，按提示使用公众号管理员微信扫码登录。
2. 进入“我的业务与服务”，选择自己的公众号，打开“基础信息”。菜单名称可能随微信界面调整，以实际页面为准。
3. 找到 **AppID**，复制备用。
4. 找到“开发密钥”或 **AppSecret**。首次使用时，按页面提示启用或生成，并完成管理员验证。显示密钥时将其保存到仅自己可访问的安全位置，稍后要填入本机配置文件。
5. 如果已经有密钥，优先使用现有值。若只看到“重置”，请先确认是否有其他工具正在使用：重置可能使原密钥失效，影响现有接入。

AppSecret 如同密码：不要发到聊天、截图、公开文档或代码仓库。配置完成后，向助手提供公众号名称和 AppID 即可，无需提供密钥。[开发者平台界面参考](https://cloud.tencent.com/developer/article/2741474)

## 三、设置 API IP 白名单

微信需要允许发起接口调用的网络出口 IP。调用公众号 API 前需要设置白名单，参见[腾讯云说明](https://cloud.tencent.com/document/product/1301/100187)。

1. 在**运行助手的电脑和网络**上打开 [查看公网 IP](https://api.ipify.org/)，复制页面显示的地址，例如 `123.45.67.89`。这是外部服务看到的地址，请勿填写示例值。
2. 在微信开发者平台中打开目标公众号的“基础信息”，找到“API IP 白名单”，点击编辑或添加。
3. 填入刚才查到的公网 IP，按提示完成管理员验证并保存。已有白名单条目时保留原有配置。

换网络或调整代理后，出口 IP 可能变化。浏览器与助手如果使用不同代理，也可能看到不同的出口 IP；若检查返回 `40164`，请核对实际调用出口和白名单。

## 四、在 Windows 上保存配置

1. 按 **Win + R**，输入 `powershell` 并按回车。
2. 复制下面两行到 PowerShell，按回车。它们会创建配置目录并打开记事本；如果记事本询问是否创建文件，请选择“是”。

   ```powershell
   New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.config\wechat-mp" | Out-Null
   notepad "$env:USERPROFILE\.config\wechat-mp\config.json"
   ```

3. 将下面内容填入记事本，把每对引号内的示例文字替换成自己的信息，保留英文引号、冒号和逗号。`name` 是方便辨认的公众号名称。

   ```json
   {
     "appid": "这里填写公众号AppID",
     "secret": "这里填写公众号AppSecret",
     "name": "这里填写公众号名称"
   }
   ```

4. 保存为 UTF-8（无 BOM），关闭记事本。默认位置是用户主目录下的 `.config/wechat-mp/config.json`。该文件包含密钥，请限制为当前用户可读，不要分享、提交到仓库或同步到不受信任的位置。

也可以在运行助手的环境中成组设置 `WECHAT_APPID`、`WECHAT_APPSECRET`，可选设置 `WECHAT_ACCOUNT_NAME`。成组的环境变量优先于配置文件；详见[微信接入与恢复](references/wechat.md)。

## 五、检查、确认并发表

1. 告诉助手“配置好了”，并提供**公众号名称和 AppID**；不要发送 AppSecret。
2. 请助手检查连接，并展示目标账号、操作、文章标题及预览。连接检查通过只表示凭据及网络检查成功，不能保证草稿和素材接口可用；其权限需在后台查看并通过实际操作核实。
3. 仔细检查正文、人物关系、照片顺序和封面。确认当前版本、目标账号及新建或更新操作后，助手才会上传所需图片并写入草稿。
4. 助手返回结果后，登录[微信公众平台](https://mp.weixin.qq.com/)的草稿箱，打开文章，检查手机预览、图片、封面裁切和排版。
5. 由你在微信后台完成发表。草稿创建成功不代表文章已经发表或群发。

## 常见问题

- **找不到开发密钥或公众号：**确认使用的是该公众号的管理员微信，并在微信开发者平台选择了正确的公众号；界面名称以微信实际显示为准。
- **提示 `40164`：**通常是调用时的公网出口 IP 不在白名单中。检查网络、代理及白名单后重试。
- **提示 `48001`：**接口可能未授权。查看公众号的接口权限；是否支持草稿或素材接口需要实际核实。
- **不想配置接口：**仍可让助手生成本地预览，再到微信后台新建图文，手动复制文字、上传图片并发表。
- **草稿创建结果不明确：**先告知助手并查看后台草稿箱，避免直接重复创建。恢复步骤见[微信接入与恢复](references/wechat.md)。
