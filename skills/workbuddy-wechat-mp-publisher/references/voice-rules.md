# 去 AI 味规则

`scripts/voice.py` 的规则来源与阈值说明。目的是让「为什么这句被标红」可解释、可复现、可申辩。

## 三条总原则

### 1. 聚集才判罚

**单个信号不算数。** 一个破折号、一处排比，本身什么都不是——人也会写破折号。
同一个窗口（同一 block 或相邻 2 个 block）里，信号 ≥3 且跨 ≥2 个类别才扣分。
强类别（套话词、修辞）允许单类别成簇，但仍需同类 ≥2 条。

**为什么**：按单点判罚的系统会把好文章改得支离破碎。要先能容忍毛边，才谈得上改。

### 2. 正向指标同样计分

写得干净但没人味，一样一眼假。所以三项正向指标参与最终分数：

| 指标 | 基线 | 低于基线说明什么 |
|---|---|---|
| 细节密度（每百字加权具体物） | 1.2（纪念日 1.0） | 全是概括，没有可验证的东西 |
| 第一人称占比 | 18% | 像旁观者，没有立场 |
| 短句占比（≤12 字） | 22% | 句子都太长，没有呼吸 |

`human_score < 40` 时强制降一档——只靠「没犯错」拿不到高分。

### 3. 人写的迹象要保住，不要修掉

以下都是**特征而非缺陷**，`keep[]` 会列出来并说明理由：

- 一句只有四个字：「今天很累。」
- 句子之间不衔接，跳着说
- 同一个词反复用（作者的口头禅）
- 情绪没解决、矛盾没化解
- 具体到略显冗余的细节（「三点二十」「八块五一斤」）

**最大的风险不是改不掉 AI 味，是改成另一种模板化的口语——那还是 AI 味，只是换了个腔调。**

## 中文 AI 稿的高频特征

按危害排序。前两条是中文语境里信号最强的。

### 1. 破折号（`——`）

**为什么强**：中文写作里破折号本来就少用，而模型把它当万能停顿。
**判罚**：单句 ≥2 个；或密度 >0.33/百字且全文 ≥2 处；或全文 ≥3 处。
**注意**：数字区间（`1990—2000`）不算。

❌ 这不是一次简单的出行——它改变了我们——至少改变了我。
✅ 那次出行之后，她开始自己收书包。

### 2. 否定式排比（`不是 X，而是 Y`）

**为什么强**：模型用它制造"深刻感"，一篇文章能出现四五次。
**判罚**：全文 ≥2 次成簇；单次进 `keep`（人也会用一次）。

变体：`不只是…更是`、`不仅是…更是`、`并非…而是`、`与其说…不如说`。

❌ 这不是一次旅行，而是一次成长。这不是陪伴，而是被陪伴。
✅ 那次她学会了自己买票。

### 3. 硬禁套话词

`赋能 / 闭环 / 抓手 / 底层逻辑 / 颗粒度 / 组合拳 / 护城河 / 顶层设计 / 降本增效 / 沉浸式 / 全链路 / 生态位 / 颠覆式`

出现在生活记录里几乎不可能有正当理由。**出现即扣分**，不看成簇。

### 4. 慎用承接词

`首先 / 其次 / 再次 / 最后 / 综上 / 总而言之 / 值得注意的是 / 众所周知 / 显而易见 / 某种程度上 / 不难发现 / 由此可见 / 在这个快节奏的时代 / 让我们一起`

**判罚**：密度 >2/千字才单独计；或「套话覆盖率」——含套话的句子占比 ≥40% 且 ≥3 句，文档级扣 8 分。
**为什么**：这类词单独出现没问题，通篇都是才有问题。

### 5. 三连排比

「看到了花，看到了树，看到了天空」。

**近似识别**（不做句法分析）：单句内按 `、，` 切子句，滑窗取 3——
长度都在 2–10 字、两两长度差 ≤2、且共享首字或尾字，判为一处。
**判罚**：全文 ≥2 处成簇。
**豁免**：含数字的列举、书名/片名列举、`keep` 中的明示举例。

### 6. 句长过于均匀

**方法**：按 `。！？…` 切句，算句长（去空白字符数）的变异系数 CV。
**判罚**：句数 ≥6 且总字数 ≥120（短文本跳过，避免误伤小样本），`CV < 0.32` 扣 8 分。
**附带**：连续 4 句长度差 ≤3 字的情况出现 ≥3 次，扣 6 分（"发板"）。

### 7. 段落等长

**判罚**：`p`/`lead` 段落 ≥4 段，且 `(最大-最小)/均值 < 0.22`，扣 6 分。
**为什么**：人会突然写一个短段，模型每段都差不多长。

### 8. 空洞结尾

**词表**：`这就是生活 / 生活就是这样 / 愿我们都能 / 愿你 / 让我们 / 希望我们 / 其实人生 / 人生就是 / 时间会告诉我们 / 一切都会 / 值得被记住 / 都值得 / 才是最重要的 / 才是最珍贵的`

**判罚**：末段命中且细节密度 <1.0，扣 10 分。
**为什么不走聚集判定**：位置确定、语义明确，一句结尾升华就是一句结尾升华，不存在单点误伤。

### 9. 意义拔高

把具体事件强行接到宏大命题上：「这件小事让我明白，陪伴的意义在于……」
**识别**：结尾段出现「明白 / 意义 / 教会我 / 让我懂得」+ 抽象名词。
**处理**：这是 `empty_end` 的扩展，人工看比正则准，列给用户判断。

### 10. 同义词轮换

同一个东西换着说法叫：孩子 / 宝贝 / 小朋友 / 小家伙。
**为什么**：模型在避免重复，但人不怕重复。
**处理**：不判罚，写进 `keep[]`——「反复用同一个词是作者的口头禅」。

### 11. 机械加粗与内联小标题

每段开头 `**第一，……**`。生活记录里不需要这种结构感。
**处理**：提示删掉加粗，改成正常句子。

### 12. 万能形容词

「美好 / 温暖 / 治愈 / 惬意 / 静谧 / 温柔了岁月」。
**处理**：建议换成体感（「晒得后脖子发烫」），不硬判罚。

### 13. chatbot 残留

「希望这篇文章对你有帮助」「如果你也有类似经历，欢迎留言」。
**处理**：结尾出现即提示删除，除非用户在 `profile` 里明确要互动语。

## 打分公式

```
负向五类各自封顶，累加后从 100 里扣：
  套话词 words     ≤25
  句长节奏 rhythm  ≤20
  修辞 rhetoric    ≤20
  结构 structure   ≤15
  结尾 ending      ≤10

ai_score    = 100 - Σ扣分
human_score = 0.5×细节密度 + 0.3×第一人称 + 0.2×短句（各按基线归一，封顶 100）
final       = 0.6×ai_score + 0.4×human_score
```

| `final` | 分档 |
|---|---|
| ≥85 | 人味足 |
| 70–84 | 可用 |
| 55–69 | 明显 AI 味 |
| <55 | 机器味重 |

`human_score < 40` → 强制降一档。

## 附：24 条 AI 写作特征速查（源自 Wikipedia "Signs of AI writing"）

1. 意义拔高（elevated significance）
2. 罗列媒体名以证权威
3. `-ing` 式假深度（"highlighting the importance of…"）
4. 宣传腔（"nestled in the heart of"）
5. 模糊归因（"experts say"）
6. 模板化困境段（"Despite these challenges…"）
7. AI 高频词（delve / tapestry / testament）
8. 回避系动词（用 "serves as" 代替 "is"）
9. 否定式排比（not just X, it's Y）
10. 三连排比（rule of three）
11. 同义词轮换（elegant variation）
12. 假区间（"from X to Y" 却无实际范围）
13. 破折号滥用
14. 机械加粗
15. 内联标题列表（`**Bold lead:** rest`）
16. emoji 装饰段落
17. chatbot 残留（"As an AI…"）
18. 空洞正向结尾
19. 过度对冲（"it's important to note that"）
20. 每段结构雷同（topic sentence + support）
21. 段落长度整齐
22. 抽象名词密集（"the intersection of…"）
23. 排比句收尾
24. 句首连接词成瘾（Moreover / Furthermore）

**中文本土化后权重最高的两条：破折号、否定式排比。** 其余按上面的判罚表处理，或只提示不扣分。

## 申辩机制

用户可以否决任何判罚。做法：在 `profile.taboo` 里加白名单，或直接说「这句我就要这么写」。
agent 应当接受，并把该处记入 `keep[]`，理由写「用户明确保留」。**不要争辩第二次。**
